# 接口文档

> 前缀：`/api/v1`。成功响应统一 `{"code": 0, "data": ...}`，失败 `{"code": 错误码, "message": "...", "data": null}`。
> 交互式文档：启动后端后访问 `http://127.0.0.1:8000/docs`（OpenAPI）。

## 1. 错误码

| 码 | 含义 |
|---|---|
| 0 | 成功 |
| 1001-1006 | 仿真相关（未启动 / 对象不存在 / 状态不允许 / 配置缺失 / 启动失败 / 连接失败） |
| 2001-2002 | 路网相关 |
| 3001-3003 | 方案相关（不存在 / 配置无效 / 模型不存在） |
| 4001-4002 | WebSocket（格式错误 / 未知类型） |
| 5000 | 内部错误 |

## 2. REST 接口

### 2.1 路网

| 接口 | 方法 | 说明 |
|---|---|---|
| `/network` | GET | 当前加载路网的 GeoJSON（edge→LineString 含 lanes/speed_limit/road_type，node→Point 含 tls_id） |
| `/network/summary` | GET | 摘要：edge_count / intersection_count / tls_count / total_lane_length_km / network_density_km_per_km2 |
| `/networks` | GET | **内置路网清单**：扫描 `networks/network/` 与 `data/networks/**`，返回 `[{name, net_path, routes[], adds[]}]`（任意 SUMO 路网可直接用绝对路径启动） |
| `/networks/upload` | POST | **上传自定义路网**：multipart 字段 `files`（.net.xml 必需 + 可选 .rou.xml / .add.xml / timing*.xml），保存到 `data/networks/custom/<名字>/`，返回路网清单项 |

### 2.2 仿真控制

| 接口 | 方法 | 说明 |
|---|---|---|
| `/simulate/start` | POST | 启动仿真。body：`{"net_path","route_files","add_files","step_length","begin","end","scheme","scheme_params"}` |
| `/simulate/stop` | POST | 停止 |
| `/simulate/pause` | POST | 暂停 |
| `/simulate/resume` | POST | 恢复 |
| `/simulate/step` | POST | 手动步进 `{"steps":N}`（仅暂停态） |
| `/simulate/speed` | POST | 设置倍速 `{"speed":0|1|N}` |
| `/simulate/status` | GET | `{session_id, state, step, sim_time, scheme, vehicle_count}` |

### 2.3 指标

| 接口 | 方法 | 说明 |
|---|---|---|
| `/metrics/realtime` | GET | 全局+各路口实时指标快照 |
| `/metrics/history` | GET | 时间序列。query：`metric, start, end, interval, scope`。支持指标：avg_delay / avg_speed / throughput / queue_length / fuel / co2 |

### 2.4 方案管理

| 接口 | 方法 | 说明 |
|---|---|---|
| `/schemes` | GET | 可用方案列表（scheme_1/2/3） |
| `/schemes/{id}/config` | POST | 动作式配置 `{"action","params"}` |
| `/schemes/{id}/status` | GET | 方案运行状态 |

**方案一动作**：`switch_tod_plan / release_force / recalculate / enable_green_wave / add_corridor / get_status`

**方案二动作**：`switch_to_mappo / switch_to_scoot / switch_to_auto / train_step / save_model / load_model / set_params / get_predictions / get_status`

**方案三动作**：`reroute_fleet / register_fleet / unregister_fleet / add_restricted_zone / remove_restricted_zone / clear_restricted_zones / enable_auto_reroute / set_params / get_fleet_status / get_route_recommendations / get_congestion_map / get_status`

**`scheme_params` 约定（任意路网使用方案二）**：

| 参数 | 说明 | 示例 |
|---|---|---|
| `mode` | 控制器模式：`auto`（自动选择）/ `mappo` / `scoot` | `"auto"` |
| `mappo_weights` | MAPPO 权重路径（相对 `backend/`）。**有对应训练权重的路网用 legacy 权重**（如 `models/weights/mappo_act_full`），**未训练过的网格类路网用路网无关权重**（`models/weights/mappo_agnostic_full`，18 维固定观测，任意网格路网直接可用，无需重新训练） | `"models/weights/mappo_agnostic_full"` |

> `mode=auto` 时平台按 `mappo_weights` 维度自动匹配：观测维度与路网不匹配时自动退避使用路网无关权重（`critic_required=False`），因此任意路网都能直接 `mode=auto` 启动。

### 2.5 扰动事件

|---|---|---|

### 2.7 LLM 智能体（Traffic Copilot）

> 架构 / 工具清单 / 安全护栏详细介绍见 **`LLM智能体Agent介绍.md`**。

LLM 智能体通过自然语言调用平台能力（态势感知 / 路径规划 / 事件注入 / 调参 / 切换模式 / 生成报告），端点为普通 `def`（FastAPI 自动放入线程池，不阻塞事件循环）。需先启动仿真（`/simulate/start`），否则返回提示。

| 接口 | 方法 | 说明 |
|---|---|---|
| `/agent/chat` | POST | 发送自然语言指令。body：`{"message":"..."}`。响应 `data.reply` 为最终中文回复，`data.tool_calls` 为工具调用日志（tool/args/result） |
| `/agent/status` | GET | Agent 配置：`{model, tools[], max_steps, protocol}` |

**`/agent/chat` 响应示例**：

```json
{
  "code": 0,
  "data": {
    "reply": "建议路线 E21_1 → E1_16 → ... → E9_19，预计约 78 秒…",
    "tool_calls": [
      {"tool": "plan_route",
       "args": {"from_edge": "E21_1", "to_edge": "E9_19"},
       "result": {"ok": true, "data": {"route_edges": ["E21_1", "E1_16", "E9_19"], "travel_time_s": 78.0}}}
    ]
  }
}
```

**可用工具（9 个）**：`get_network_status`（全局指标）、`get_tls_status`（路口相位）、`get_edge_status`（道路状态）、`plan_route`（Dijkstra 最优路径，参数 `from_edge`/`to_edge`，返回边序列与预计时间）、`list_events`、`inject_event`（construction/large_event/accident）、`set_params`（min_green/max_green/switch_clearance）、`switch_mode`（mappo/scoot）、`generate_report`（态势报告）。

> 说明：LLM 输出经工具白名单 + 参数范围校验后才执行（如 `switch_clearance` 下限 5），越界会被拒绝并反馈，模型自动纠正。

## 3. WebSocket（`/ws`）

统一消息 `{"type": ..., "data": {...}, "timestamp": 仿真步}`。

**服务端→客户端**：`connected` / `simulation_step` / `vehicle_update`（added/updated/removed 增量）/ `tls_update`（状态变化时）/ `metrics_update`（每 60 步，含 emissions）/ `simulation_event`。

**客户端→服务端**：`set_speed` / `pause` / `resume` / `stop` / `step` / `set_update_interval` / `set_viewport`（视域裁剪）/ `subscribe`。

非法消息不崩溃，返回 `simulation_event`（event_type=error）。

## 4. 配置（.env）

| 键 | 说明 | 默认 |
|---|---|---|
| SUMO_HOME | SUMO 安装路径 | 空 |
| SIM_CONFIG_PATH | 默认仿真配置路径 | 空 |
| BACKEND_PORT | 后端端口 | 8000 |
| SUMO_COMM_PORT | 引擎通信端口 | 8813 |
| STEP_LENGTH / BEGIN_TIME / END_TIME | 仿真默认参数 | 1.0 / 0 / 86400 |
| LLM_PROVIDER | LLM 后端预设：`ollama`（本地免费离线，默认）/ `zhipu`（智谱免费 API） | `ollama` |
| LLM_BASE_URL | LLM 服务地址（OpenAI 兼容）。默认本地 Ollama；显式设置时覆盖预设 | 按预设 |
| LLM_MODEL | 模型名。ollama 预设 `qwen2.5:3b`；zhipu 预设 `glm-4-flash`；可显式覆盖 | 按预设 |
| LLM_API_KEY | API 密钥。**智谱预设留空占位**，填真实密钥即可用（`/agent/status` 的 `api_key_configured` 可查状态） | 按预设 |

> Postman 集合见 `docs/postman/collection.json`（可再从 OpenAPI 重新导出）。
