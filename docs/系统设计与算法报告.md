## 三、协同管控算法原理

### 方案一 分时多算法切换
- TOD 时段调度、Webster 最优配时（公式推导）、MAXBAND 绿波协调（走廊检测/偏移）

### 方案二 实时观测自适应
- **SCOOT 自适应控制**：规则决策（保持/切换/延长）、周期自适应、绿信比按需求分配
- STGCN 交通流预测（图结构 + 时间卷积）
- **MAPPO 强化学习（已修复训练坍缩，作为主控之一）**：
  - **actuated"保持/推进"动作空间**（KEEP=延长绿灯 / ADVANCE=触发变灯倒计时→黄红过渡→下一绿灯阶段，阶段轮转由程序保证、方向永不饿死）
  - **真实变灯语义**：变灯倒计时 12s + 黄灯 3s + 红灯 1s，杜绝"绿灯瞬间变红"
  - 奖励：压力改进式 + Δ排队 + 未服务排队惩罚 + 空放持有惩罚
  - 算法：参数共享 Actor + 中心化 Critic、真实 on-policy PPO（log-softmax 修正）、GAE、ε-混合行为策略 logp、熵退火、数据录制、断点续训
  - **结果（routes_clean700 贪心窗口均值）**：veh=49 / speed=1.77 / wait=45s，优于 SCOOT（63.5/1.71/60）；训练方法见 `docs/MAPPO训练与验证指南.md`
