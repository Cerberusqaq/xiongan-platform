## 1. 实验设计

| 项 | 配置 |

| 扰动场景 | 施工占道 / 突发车流 / 事故（events/inject） |

## 2. 指标定义

| 指标 | 定义 | 来源 |
|---|---|---|
| 平均行程时间 | 车辆平均实际行程用时（s） | tripinfo / 引擎 |
| 排队长度 | 各交叉口排队车辆均值（辆） | DataCollector 路口指标 |
| 通行能力 | 单位时间通过车辆数（veh/h） | total_throughput 差分 |
| 燃油消耗 | 累计油耗（L） | SUMO emissions |
| CO2 排放 | 累计排放（g） | SUMO emissions |
| 平均延误 | 自由流与实际速度差均值（s/veh） | DataCollector 全局指标 |
| 综合评分 | 效率^0.5 × 稳定^0.3 × 公平^0.2（硬性筛选 + P95 尾部风险） | scoring.py |

### 3.1 MAPPO 方案二实测验收数据（routes_clean700，贪心推理窗口均值）

| 方案 | veh（在网车辆） | avg_speed（m/s） | avg_waiting_time（s） |
|---|---|---|---|
| 固定配时（安全基线） | 38.5 | 3.07 | 25 |
| SCOOT 自适应 | 63.5 | 1.71 | 60 |
| **MAPPO（actuated，训练后贪心）** | **49.0** | **1.77** | **45** |
| 修复前 MAPPO（历史坍缩死锁） | 171~185 | 0.27~0.32 | 135~145 |

> MAPPO 三项均优于 SCOOT，验收通过；训练与复现命令见 `docs/MAPPO训练与验证指南.md`。
> 说明：SCOOT 基线走瞬间跳变分支，MAPPO 走真实变灯语义（12s 倒计时 + 黄红过渡），
> 即 MAPPO 在更严苛约束下仍优于 SCOOT。

## 4. 分析框架

1. 相对基线提升百分比（行程时间↓、排队↓、通行能力↑、油耗↓）
2. 不同流量负荷下的鲁棒性（高负荷是否退化）
3. 扰动场景下的恢复能力（注入后指标恶化幅度与恢复时间）
4. 方案间权衡：scheme_1 稳定性 vs scheme_2 自适应 vs scheme_3 车端响应
