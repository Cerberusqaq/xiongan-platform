# 实际场景演示方案

> 目标：一段 5-8 分钟剪辑视频，展示"场景导入 → 算法部署 → 实时协同调控 → 效果对比"全过程，关键数据指标叠加显示。

## 1. 场景定义

**雄安容东片区高峰拥堵路口群（20 路口片区）**

- 问题：早高峰主干道绿波失效、次干道排队溢出、交叉口相互影响
- 指标基线：固定配时下的平均延误、排队长度、油耗

## 2. 演示流程（脚本分镜）

| 幕 | 内容 | 时长 | 叠加指标 |
|---|---|---|---|
| 1 | 场景导入：路网 GeoJSON 渲染，20 路口高亮，背景介绍 | 40s | 路口数、边数 |
| 2 | 问题呈现：固定配时运行，主干道拥堵蔓延 | 60s | 平均延误↑、排队长度↑、平均速度↓ |
| 3 | 算法部署：切换 scheme_1，TOD 时段 + Webster 重算 + 绿波协调 | 60s | 配时方案可视化、走廊偏移 |
| 4 | 边缘自适应：切换 scheme_2（MAPPO/SCOOT），路口信号实时调整 | 90s | 每路口相位、决策频率 |
| 5 | 车端引导：切换 scheme_3，公交/网约车动态改道 | 60s | 重路由事件、节省时间 |
| 6 | 扰动测试：注入施工占道 / 突发车流，观察协同调控响应 | 60s | 事件日志、拥堵地图 |
| 7 | 效果对比：三方案 vs 固定配时汇总图表 | 60s | 行程时间/排队/油耗/通行能力对比 |

## 3. 演示操作流程

1. 启动后端（`start.bat` 或 uvicorn）
2. `POST /simulate/start` 指定路网 + 固定配时（baseline）
3. 依次 `POST /simulate/start` scheme_1/2/3 各跑一段
4. `POST /events/inject` 注入扰动
5. 前端录屏 + 指标面板叠加（OBS 录制）

## 4. 演示要点

- **对比直观**：同机位同路网，三方案与基线并排或叠加曲线
- **数据叠加**：用前端指标面板/图表实时覆盖（延误、排队、速度）
- **解说**：突出"云-边-端"协同——云端协调绿波、边缘路口自适应、车端改道
- **可选彩蛋**：真多机演示（云端一台电脑、边缘一台跑 RSU 模拟，V2X 走 SocketTransport）

## 5. 素材清单

- 视频：3 段（导入、协同调控、效果对比）剪辑为 5-8 分钟
- 图表：延误/排队/油耗对比柱状图、时间序列曲线
- 数据表：评估报告结果表
