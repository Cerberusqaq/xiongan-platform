# 前端可视化规范（未实现，供前端负责人实现）

> 本目录仅包含前端技术选型与数据契约，代码由团队前端同学实现。
> 页面/元件规划、亮点展示与优先级见 **《前端设计建议.md》**。

## 技术选型

| 用途 | 选型 |
|---|---|
| 框架 | Vue 3 + Vite |
| 地图底图 | MapLibre GL（容东片区矢量瓦片，可离线自托管） |
| 车辆/信号灯渲染 | deck.gl（instanced 渲染，支持 3000+ 车辆 30fps） |
| 图表 | ECharts |
| 通信 | 原生 WebSocket + Fetch |

## 页面结构

1. **路网可视化页**：地图底图 + 车辆图层 + 信号灯图层 + 控制面板 + 指标面板 + 图表 + 事件日志 + 底部状态栏
2. （可选）方案配置子面板：按选中方案动态显示操作按钮

## 数据契约

- 路网：`GET /api/v1/network`（GeoJSON FeatureCollection；edge→LineString，node→Point）
- 控制：`POST /api/v1/simulate/*`、`/api/v1/schemes/*`、`/api/v1/events/inject`
- 实时：WebSocket `/ws`
  - `vehicle_update`：`{added:[{id,x,y,angle,speed,type,...}], updated:[{id,x,speed,...}], removed:[id]}` — **增量渲染**
  - `tls_update`：`{tls_id:{state_str,phase_index,...}}` — 状态变化时推送
  - `metrics_update`：每 60 步，`{overall:{...}, emissions:{...}}`
  - `simulation_event`：事件日志
- 指标历史：`GET /api/v1/metrics/history?metric=avg_delay&start=..&end=..&interval=..`

## 渲染要点

- 车辆按类型着色：passenger 蓝 / bus 红 / fleet 橙 / truck 紫 / bicycle 绿
- 视域裁剪：WS 发送 `set_viewport` 只收视域内车辆，降低传输量
- 信号灯：交叉口位置绘制状态指示，颜色对应 state_str（G/R/y）
